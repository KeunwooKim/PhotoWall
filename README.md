# PhotoWall

네컷사진을 자유 배치하는 디지털 포토월 (Next.js + PixiJS).

라이브: [photowall.kr](https://photowall.kr) — 계정 없이 `/wall/edit`에서 바로 꾸밀 수 있습니다.

## 로컬 실행

```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run dev                  # http://localhost:3000
```

```bash
npm run build && npm start
```

## 점검

```bash
npm run typecheck
npm run lint
npm run build
```
