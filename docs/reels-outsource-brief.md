# PhotoWall 홍보 릴스 1편 — 외주 제작 기획안 / 브리프

> **버전:** 1.0 · **대상:** 크리에이터 / 숏폼 영상 외주팀  
> **산출물:** Instagram Reels 1편 (15–30초, 9:16)  
> **서비스:** [https://photowall.kr](https://photowall.kr)

이 문서는 내부 기획과 외주 브리프를 겸합니다. 추가 미팅 없이 1편 제작을 시작할 수 있도록 샷·카피·에셋·납품 기준을 고정했습니다.

---

## 1. 프로젝트 개요

### 한 줄 정의

오프라인 매장·방 벽에 네컷사진을 마스킹 테이프로 비뚤게 붙이던 감각을 디지털로 옮긴 **Z세대 취향 저격 가상 벽 꾸미기(Wall-꾸) 소셜 플랫폼**.

### 왜 릴스인가

- 제품의 차별점은 “반듯한 그리드 아카이브”가 아니라 **붙이고·돌리고·꾸미는 손맛**이다. 숏폼이 이 감각을 가장 잘 전달한다.
- 핵심 CTA가 **체험**(`계정 없이 바로`)이므로, 기능 설명 PPT보다 **15–30초 데모 스토리**가 전환에 유리하다.
- 인스타 스토리 공유가 제품 기능이므로, 릴스 → 프로필 링크 → 앱 체험 루프가 자연스럽다.

### 포지셔닝 (외주가 오해하면 안 되는 점)

| 아닌 것 | 맞는 것 |
|---|---|
| 네컷 고화질 저장·그리드 앨범 앱 | 벽에 **비뚤게** 붙이고 꾸미는 디지털 쇼룸 |
| 패션/인테리어 무드보드 | **개인의 네컷·추억**이 주인공 |
| 기능 나열형 앱 소개 | 한 편의 감성 스토리 + 핵심 기능 3개만 |

## 2. 캠페인 목표 · KPI

### 목표 (이번 1편)

**핵심 기능 교육** — 시청자가 “아, 네컷을 디지털 벽에 비뚤게 붙이고 스티커·테이프로 꾸민 뒤 공유하는 서비스구나”를 한 번에 이해하게 한다.

부차: 프로필/링크 클릭 → `photowall.kr` 유입 → 게스트 체험(`/wall/edit`).

### 권장 KPI (측정 가능한 것만)

| 지표 | 기준 (가이드) | 비고 |
|---|---|---|
| 평균 시청 유지율 | 50% 이상 (25초 기준) | 훅 3초·CTA 전 이탈 최소화 |
| 프로필 방문 / 링크 클릭 | 업로드 후 7일 트래킹 | 바이오 링크 = photowall.kr |
| 랜딩·에디터 유입 | UTM 또는 링크 단축 트래킹 | 예: `?utm_source=ig&utm_medium=reels&utm_campaign=launch_r1` |
| 저장·공유 수 | 참고 지표 | 바이럴 신호 |

예산·단가는 본 문서에 포함하지 않는다.

## 3. 타깃 · 페르소나 (1편)

### 타깃

- **Z세대** (10대 후반–20대), 한국 **인생네컷 / 포토이즘** 문화에 익숙한 사람
- 방·기숙사·카페 벽에 네컷을 테이프로 붙여 본 경험이 있는 사람
- 인스타 릴스·스토리를 자주 올리는 사람

### 1편 주인공 페르소나 (고정)

**커플 — “우리의 시간”**

- 이유: 기존 프로모 에셋(`public/promo/strips/`, `public/promo/photos/`)이 가장 풍부하고, 랜딩 쇼케이스 첫 탭과 일치한다.
- 화면에서 보이는 관계: 데이트·카페·밤거리·집 코지 등 **2인 네컷·스냅**이 벽에 쌓이는 느낌.
- (친구/펫 버전은 시리즈 확장용으로만 남겨 두고, **이번 1편에는 쓰지 않는다.**)

### 한 편에 넣을 기능 (우선순위 고정)

## 5. 브랜드 가이드 (영상용 축약)

### 로고

- 워드마크: `Photo` + **rose** `Wall`  
- 예: Photo<span style="color:#ff5b8d">Wall</span>  
- CTA·엔딩 카드에만 쓰고, 영상 전체에 과도하게 워터마크하지 않는다.

### 컬러

| 이름 | Hex | 용도 |
|---|---|---|
| Cream | `#faf7f2` | 배경·엔딩 카드 밝은 면 |
| Charcoal | `#1c1917` | 본문·다크 CTA |
| Rose | `#ff5b8d` | 브랜드 포인트·CTA·로고 Wall |
| Cork | `#c9a97a` | 밑줄·따뜻한 포인트 |
| Muted | `#9b8e82` | 보조 문구 |
| Mint | `#4a9b83` / `#b8e0d2` | “체험 가능” 등 상태 포인트 (선택) |

### 비주얼 언어

- 코르크보드 / 흰·적 벽돌 / 매직파티션 등 **실감 있는 벽 질감**
- 흰 테두리 네컷 스트립, **의도적으로 기울어진** 배치
- 마스킹 테이프, 스티커, (선택) 핀 감성
- 손글씨 느낌 자막 (Gaegu / Jua / Caveat 계열). 시스템 기본 산세리프만으로 채우지 말 것.

### 모션

- 부드럽고 짧은 손맛 (붙이기, 살짝 돌리기, 테이프 붙이기)
- 랜딩의 float/reveal처럼 **과하지 않은** 움직임
- 기능 강조용으로 UI를 과도하게 줌인·하이라이트 박스로 도배하지 말 것

### 금지

- 반듯한 **그리드 아카이브** UI를 제품의 주된 모습으로 보여 주기  
- 퍼플·인디고 그라데이션, 네온 글로우, 대시보드형 카드 콜라주  
- 가짜 앱 목업을 실서비스처럼 가장 (실서비스 또는 공식 프로모 화면 사용)  
- 기능 아이콘 6개를 나열하는 PPT형 컷  
- 이모지·스티커를 화면 전체에 난사해 제품 UI를 가리기

## 7. 스토리보드 (초 단위) — 1편

**총 길이:** 약 **25초** (허용 15–30초)  
**콘셉트:** 실물 네컷 → 디지털 벽에 비뚤게 붙이기 → 꾸미기 → 공유  
**페르소나:** 커플

| 시간 | 화면 | 액션 / 연출 | 자막 |
|---|---|---|---|
| **0.0–3.0s** | 실물 네컷 스트립을 손에 든 클로즈업, 또는 방 벽에 테이프로 붙인 네컷 스틸 → 살짝 기울어짐 | 훅. 아날로그 감성. 빠른 컷 OK | 방 벽에 붙이던 그 감각 |
| **3.0–5.5s** | 폰 화면: PhotoWall 에디터(코르크/매직파티션). 빈 벽 또는 거의 빈 벽 | 앱 진입. 로고는 작게만 | 네컷, 디지털 벽에 |
| **5.5–9.0s** | 네컷 스트립이 벽에 나타나고, 손가락(또는 커서)으로 **비스듬히** 돌리며 배치 | **핵심 기능 1** — 비뚤게 붙이기. 반듯한 정렬 금지 | 비뚤게 붙여도 돼 |
| **9.0–13.0s** | 마스킹 테이프 붙이기 → 하트/카페 스티커 2–3개 추가. 스냅 사진 1장 더 붙임 | **핵심 기능 2** — 테이프·스티커. 손맛 있는 템포 | 테이프랑 스티커로 |
| **13.0–17.0s** | 완성된 커플 포토월 **풀샷** (프로모 월에 가까운 밀도). 살짝 줌아웃 | “와, 내 벽이다” 비트 | 내 취향 그대로 |
| **17.0–19.5s** | (선택 1비트) 친구 커서·아바타 또는 “○○님이 네컷을 붙였어요” 토스트가 잠깐 지나감 | **공동 벽 힌트만**. 설명 자막 길게 쓰지 말 것 | (자막 없음 또는) 같이도 꾸며요 |
| **19.5–22.5s** | 공유 시트 / 벽 캡처 이미지 + 인스타 공유 제스처 | **핵심 기능 3** | PhotoWall에서 꾸민 내 벽이에요! |
| **22.5–25.0s** | 엔딩 카드: cream 배경 + rose CTA | 로고 + URL + 체험 문구 | photowall.kr · 계정 없이 바로 체험 |

### 썸네일 후보 (정지 컷 3안)

1. 기울어진 네컷 + 마스킹 테이프가 돋보이는 벽 클로즈업  
2. 완성 커플 포토월 풀샷 + 손글씨 자막 「비뚤게 붙여도 돼」  
3. 엔딩 CTA 카드 (Photo**Wall** + photowall.kr)

**기본: 없음 (자막 + BGM).**  
VO를 넣을 경우 톤은 친근한 반말·해요체, 15초 이내 한 문단만.

- 무드: 따뜻하고 가벼운 DIY / 카페·데이트 감성

## 9. 촬영 · 제작 스펙

| 항목 | 스펙 |
|---|---|
| 비율 | **9:16** |

| UI 진실성 | **실서비스 photowall.kr** 또는 공식 프로모 월 비주얼. 임의 재디자인 목업 금지 |

### 스크린레코딩 팁

- 데모 전 게스트 에디터에서 벽을 한 번 리셋하거나, 촬영용으로 깔끔히 준비한 뒤 “붙이는 과정”만 녹화  
- 다크 모드·시스템 알림·배터리 아이콘 등 방해 요소 제거  
- 손가락 제스처가 보이면 좋으나, 필수 아님 (커서·자동 배치 연출 가능)

## 10. 외주 범위 · 납품물

### 포함

- 기획안(본 문서) 기반 **1편** 촬영·스크린레코딩·편집·자막·컬러·사운드  
- 썸네일 후보 **3장** (png/jpg)  
- 최종 영상 **1본** + 수정 반영본  
- 사용 음원 **라이선스 증빙**  
- (가능 시) 편집 프로젝트 원본, SRT

### 포함하지 않음

- 계정 운영·게시 대행 (별도 요청 시)  
- 유료 광고 세팅  
- 2편 이후 시리즈 기획  
- 앱 내 기능 개발·버그 수정  

### 수정 라운드

- **피드백 2회** 포함 (1차 러프컷 → 2차 파인컷 → 파이널)  
- 3회차부터는 범위·비용 재협의  
- 피드백은 “브랜드 가이드·스토리보드 대비 어긋난 점”을 우선으로 수렴

### 일정 템플릿 (예시)

| 단계 | 일차 (예시) | 산출 |
|---|---|---|
| 킥오프 · 에셋 전달 | D0 | 본 브리프 + 이미지·계정 접근 |
| 러프컷 | D+5 | 샷 순서·템포 확인용 |
| 1차 수정 | D+8 | 자막·CTA·브랜드 검수 |
| 파인컷 | D+11 | 거의 최종 |
| 파이널 납품 | D+14 | mp4 + 썸네일 + 라이선스 |

실제 일정은 계약 시 확정.

## 11. 검수 체크리스트

납품 전 클라이언트·외주 공통 확인.

### 브랜드

- [ ] 로고가 `Photo` + rose `Wall` 규칙을 따르는다  
- [ ] cream / rose / charcoal 톤이 유지되고, 금지 비주얼(퍼플 글로우·그리드 앨범)이 없다  
- [ ] 손글씨 감성 자막이 쓰였거나, 동등한 따뜻한 타이포다  

### 기능·스토리

- [ ] “비뚤게 붙이기”가 명확히 보인다 (반듯한 정렬만 나오지 않는다)  
- [ ] 마스킹 테이프와 스티커가 각각 최소 1회 이상 보인다  
- [ ] 완성 벽 풀샷이 있다  
- [ ] 공동 벽은 있어도 **1비트 이하**이며 메인 줄거리를 덮지 않는다  
- [ ] 공유/인스타 비트가 있거나, CTA로 대체되어도 메시지가 끊기지 않는다  

### CTA · 법적

- [ ] `photowall.kr` 표기가 엔딩에 있다  
- [ ] 「계정 없이 바로 체험」 또는 동등 CTA가 있다  
- [ ] 음원·이미지·인물 초상권 라이선스가 확보되었다  
- [ ] 프로모 에셋 외 무단 스톡/유명인 이미지를 쓰지 않았다  

### 기술

- [ ] 9:16, 1080×1920 이상  
- [ ] 15–30초  
- [ ] 자막이 safe area 안에 있다  
- [ ] 최종 mp4 재생·인스타 업로드 테스트 통과
